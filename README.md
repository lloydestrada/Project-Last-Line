# ProjectLastHouse
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "ProjectLastHouse.rbxlx"
```

Next, open `ProjectLastHouse.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

The server generates the lobby automatically at startup. The visual effects are
configured in `src/server/Services/LobbyBuilder.lua`:

- `Animate` controls holograms, searchlights, and pulsing lights.
- `Particles` controls sparkles, low atmospheric smoke, and drifting dust motes.
- `Skyline` controls the ruined city backdrop.
- `ArrivalGate` controls the illuminated arrival arch.

Players enter through a short cinematic camera sequence with a responsive HQ
status overlay and contextual facility callouts. The client presentation is
implemented in `src/client/Controllers/LobbyController.lua`.

For more help, check out [the Rojo documentation](https://rojo.space/docs).
